# Архитектура

## Общий принцип

Фреймворк построен на **Extensions** (расширениях). Каждое расширение — папка с тремя файлами:

```
Extension/
├── Extension.toml   # манифест
├── Extension.py     # публичное API
└── _lib/
    └── extension_lib.py  # внутренняя реализация
```

## GPU-first

Все `_lib` внутри используют CuPy.
Если среда не имеет NVIDIA GPU — фреймворк бесшовно переключается на CPU.
Публичное API возвращает `xp.ndarray`, никогда не вызывая `.tolist()` / `.get()`.

## Загрузка

`framework_builder.ExtensionsLoader` сканирует корневую папку, находит `.toml`-манифесты и загружает модули.

## Список расширений

| Модуль   | Папка     | Назначение                       |
|----------|-----------|----------------------------------|
| `_main`  | `_main/`  | Ядро: версия, статус             |
| `Series` | `Series/` | Ряды на CuPy (GPU)               |
| `Tables` | `Tables/` | Таблицы на CuPy (GPU)            |
| `Memory` | `Memory/` | Кэш с TTL                        |
| `Mods`   | `Mods/`   | Декораторы и Registry            |
| `Proxy`  | `Proxy/`  | Ленивая загрузка                 |

## Схема

```
┌──────────────────────────────────────────────────────────────┐
│                     numfast (ExtensionsLoader)               │
├──────────┬──────────┬──────────┬──────────┬──────────┬───────┤
│  _main   │  Series  │  Tables  │  Memory  │   Mods   │ Proxy │
│ (ядро)   │ (ряды)   │ (таблицы)│ (память) │ (моды)   │(прокси)│
├──────────┴──────────┴──────────┴──────────┴──────────┴───────┤
│            CuPy (GPU) / CPU-режим (автоматически)            │
└──────────────────────────────────────────────────────────────┘
```
