# Проект NumFast

## Цель

Создать лёгкий фреймворк для численных расчётов на Python с модульной архитектурой.
CuPy — обязательная зависимость, обеспечивающая GPU-ускорение.
При отсутствии NVIDIA GPU вычисления прозрачно выполняются на CPU.

## Мотивация

CuPy — единственный вычислительный бэкенд NumFast.
Он предоставляет знакомый API, при этом работая на GPU.
Если GPU нет — фреймворк сам переключается на CPU,
без правки кода и установки дополнительных пакетов.

## Принципы

- CuPy-first — все численные операции уходят на GPU через CuPy
- Прозрачный CPU-режим — если GPU нет, код работает на CPU без изменений
- Минимализм — каждая функция делает одно дело
- Модульность — каждый компонент — отдельное расширение

## Технологии

- Python >= 3.11
- CuPy >= 13.0 (GPU-ускорение; CPU — автоматически)
- Rich >= 13.0
- framework-builder >= 0.1.0
