# NumFast Logo Assets

## Files

| File | Description | Usage |
|------|-------------|-------|
| `logo-icon.svg` | Square icon (512x512) with gradient bg | GitHub avatar, social media |
| `logo-horizontal.svg` | Full logo with text | GitHub repo header, docs |
| `logo-icon-light.svg` | White icon, transparent bg | Dark theme websites |
| `logo-icon-dark.svg` | Dark blue icon, transparent bg | Light theme websites |

## Colors

- Deep blue: `#0d47a1`
- Cyan: `#00bcd4`
- Dark cyan: `#00838f`
- Gradient: deep blue -> dark cyan

## Design

The mark is an abstract "N" (NumFast) built from three parallel vertical bars —
representing GPU cores working in parallel. Three thin horizontal lines across
the N symbolize data streams flowing through the compute pipeline.
