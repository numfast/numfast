# NumFast Logo Assets

## Concept: "The Accelerator"

Three parallel bars — GPU cores working in parallel.
Forward taper — speed, acceleration, fast.
Diamond arrowhead — precision, execution.

Not a letter mark. A symbol of motion and parallel compute.

## Files

| File | Description | Usage |
|------|-------------|-------|
| `logo-icon.svg` | Square icon (512×512) with gradient bg | GitHub avatar, social media |
| `logo-horizontal.svg` | Full logo with text | GitHub repo header, docs |
| `logo-symbol.svg` | Standalone symbol, no bg | Favicon, watermark |
| `logo-icon-light.svg` | White symbol, transparent bg | Dark theme websites |
| `logo-icon-dark.svg` | Dark blue symbol, transparent bg | Light theme websites |

## Colors

- Electric blue: `#1565C0`
- Bright cyan: `#00E5FF`
- Gradient: electric blue → bright cyan
