# Linear Regression

**Задача:** Подобрать коэффициенты линейной регрессии методом наименьших квадратов.

**Метод:** Нормальные уравнения β = (X^T X)^{-1} X^T y через matmul().

**Почему NumFast:** Матричное умножение — основная операция, реализованная
на GPU через tiled matmul с разделяемой памятью.

**Запуск:**
```bash
cd apps/linear_regression
python run.py
```

**Ожидаемый результат:** Коэффициенты регрессии, близкие к истинным.
