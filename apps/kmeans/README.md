# K-Means Clustering

**Задача:** Разбить данные на K кластеров методом K-средних.

**Метод:** Итеративное уточнение центроидов через вычисление расстояний.

**Почему NumFast:** Сортировка и вычисление расстояний на GPU ускоряют
каждую итерацию при большом числе точек и признаков.

**Запуск:**
```bash
cd apps/kmeans
python run.py
```

**Ожидаемый результат:** 3 кластера с центроидами около (0,0), (5,5), (10,0).
