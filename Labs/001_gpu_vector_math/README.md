# Lab 001: GPU Vector Math

## Что делает

Демонстрирует базовые поэлементные операции на GPU:
- Copy: копирование массива
- AddConstant: прибавление константы к каждому элементу
- Multiply: поэлементное умножение двух массивов

## Как запустить

```bash
cd numfast
python -m Labs.001_gpu_vector_math.jobs
```

## Что изучить

- Как ядро регистрируется через register_kernel()
- Как describe() описывает требования ядра
- Как cpu() реализует эталонную логику
- Как wgsl-шейдер выглядит для простых операций
- Как Runtime компилирует и выполняет задачи
- Как сравнить CPU и GPU результаты

## Структура

- `jobs.py` — регистрация ядер + выполнение + сравнение
- `spec.md` — спецификация для агента
- `expected/` — .npy эталоны (генерируются при первом запуске)
