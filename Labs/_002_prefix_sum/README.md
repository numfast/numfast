# Lab 002 — Inclusive Prefix Sum (Scan)

## Что это

Inclusive prefix sum (aka scan) — каждый элемент выходного массива содержит
сумму всех предыдущих элементов входного массива включительно:

```
input:  [a0, a1, a2, a3, ...]
output: [a0, a0+a1, a0+a1+a2, a0+a1+a2+a3, ...]
```

## Почему это важно

Scan — фундаментальный параллельный алгоритм. Используется в:
- радиксной сортировке
- stream compaction
- выделении памяти
- работе с разреженными данными
- как building block для более сложных операций

## Архитектура

Реализация — трёхфазный multi-workgroup scan:

1. **ScanLocal** — каждый workgroup (64 threads) вычисляет локальный prefix sum
   и сумму блока
2. **ScanTotals** — последовательный scan массива блочных сумм
3. **ScanFinal** — прибавление накопленного смещения блока к локальным суммам

## Точность

Для int-подобных данных (например, `[0, 0.5, 1.0, 1.5, ...]`) точность
ограничена IEEE754 float32. Относительная ошибка для 100k элементов — ~0.07%.
Для приложений, требующих бит-в-бит повторяемости, см. Future Numeric Policies
в ADR-004.
