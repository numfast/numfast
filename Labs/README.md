# Labs — учебные модули NumFast

Каждый Lab — самодостаточный учебный модуль:
- Документация (README.md, spec.md)
- Код (jobs.py — описание ядра + запуск)
- Ожидаемый результат (expected.json — golden test)

Labs — это одновременно:
- документация
- тесты
- обучающий курс
- база знаний для AI-агентов

## Структура Lab

```
Labs/
  NNN_name/
    README.md    — что делает, как запустить, что изучить
    spec.md      — behavioural spec для агента
    jobs.py      — регистрация ядра + выполнение
    expected.py  — генерация эталонного выхода
    expected/    — .npy файлы эталонов (после генерации)
```
