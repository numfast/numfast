# ALGORITHM_RESEARCH_PROTOCOL (норма)

## PURPOSE

Единый закон всех алгоритмических исследований NumFast. Нарушение = результат недействителен.

## 1. ПРИНЦИП КАНДИДАТА

1. Новый алгоритм сначала — отдельная research function, НЕ замена существующего кода.
2. Все кандидаты одного исследования — один input/output контракт (как `contract.py` в `groupby_lab/`).
3. Исследовательскую функцию после сравнения НЕ выбрасывать — оставлять в research corpus для будущих матриц.

## 2. ЭТАПЫ (порядок обязателен)

1. `MICROBENCH` — маленькие блоки + synthetic, seed 42. Отсев грубых регрессий.
2. `CROSS-STRATEGY MATRIX` — каждый кандидат против текущего лучшего на всех режимах (размер блока × уникальность × распределение).
3. `REAL NUMFAST PATH` — настоящий public путь `Schema → IR → Planner → Runtime → CPU`. Замеры вне пути — не proof.
4. `H2O 10M Q1–Q5` — полный прогон.
5. При улучшении на 10M — `H2O 100M`.
6. Только потом — сравнение с DuckDB/Polars.

ЗАПРЕЩЕНО: объявлять кандидата победителем только по microbenchmark.

## 3. КАРТОЧКА КАНДИДАТА (сохранять для каждого)

- `algorithm` — что реализовано, чем отличается.
- `input regime` — размер блока, распределение, уникальность.
- `group count` — число групп на входе/выходе.
- `time` — ms + stage breakdown.
- `memory` — байты состояния, пик.
- `correctness` — сверка с эталоном (bit-identical или max_diff).
- `speedup vs current best` — отношение к лучшему на том же режиме.

Без карточки кандидат в сравнение не входит.

## 4. PLANNER INTEGRATION

Только после end-to-end proof на REAL NUMFAST PATH + H2O. Интеграция в Planner без proof запрещена.

## 5. УРОК ЛАБОРАТОРИИ: РАСШИРЕНИЕ СОСТОЯНИЯ

Partial aggregation может раздувать данные: при высокой уникальности L1-состояние (9.9MB) > raw входа (4.7MB). Проверять расширение состояния явно для каждого кандидата: `state_bytes` vs `raw_bytes` на каждом режиме.

## 6. KILL-ПРАВИЛА

1. `<20%` выигрыша на режиме — не тащить дальше без письменного обоснования.
2. Стратегию глобально не отклонять по одному режиму — вердикт только по полной матрице.
